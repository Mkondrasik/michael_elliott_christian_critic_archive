# Internet Archive preservation workflow

For each review:

1. Preserve the original source scan privately.
2. If the working copy contains later handwriting or symbols, create a clean public-facing scan with those later annotations removed.
3. Confirm that historical phone numbers, email addresses, postal addresses, and URLs are understood as historical contact information.
4. Deposit the approved public scan and, where useful, the author-verified text/metadata at Internet Archive.
5. Copy the Internet Archive item URL into the review record’s `internet_archive_url` field.
6. Add a visible “View preserved source at Internet Archive” link to that review page.

Source types used by this project include **Original Author Copy**, **Reconstructed Author Copy**, **Published Web Version**, and **Third-Party Reprint**. `Elliott_0006` (Whipped) is a Reconstructed Author Copy, retyped by the author in August 2026 after damage to the paper original.
