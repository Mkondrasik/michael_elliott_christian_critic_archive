# Spiritual Theme Normalization

Normalizes all Sermon / Spiritual Topic labels to consistent Title Case and merges entries that differed only by capitalization.

Examples:
- `hope` and `Hope` → `Hope`
- `christian witness` and `Christian Witness` → `Christian Witness`
- `good and evil` and `Good and Evil` → `Good and Evil`

Upload these files to the repository root, preserving folder paths, and replace files with the same names.
