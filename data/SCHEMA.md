# Review metadata schema

Key public fields: `id`, `title`, `author`, `byline`, `series`, `publication_date`, `rating`, `scripture_references`, `primary_scripture`, `translation`, `sermon_spiritual_topic`, `source_type`, `verification_status`, `internet_archive_url`, and `page`.

`publication_date` is null unless the original publication date has been established. Legacy dates inherited from printed/reused templates are deliberately excluded from the public repository.
